# Embedded Health Backend API

This backend provides a **retrieval-augmented generation (RAG) agent API** over a database of diseases and patient symptom statements. It uses **vector embeddings** generated by the `qwen3-embedding` model from Ollama and performs vector similarity searches in MongoDB to return the most relevant disease or symptom descriptions. The agent then post-processes these results, assesses seriousness, and can generate treatment plans or recommend nearby care.

---

## Features

- Graph-based agent workflow with tool-based RAG capabilities.
- Semantic search over a database of diseases and patient symptom statements using natural language queries.
- Returns results ranked by semantic similarity and post-processed by an LLM.
- Can assess seriousness, generate treatment plans, and suggest nearby care facilities.
- Easy-to-use REST API endpoint.
- Built with Node.js, Express, MongoDB, and Ollama embeddings.

---

## Tech Stack

- **Node.js** and **Express** – backend server and API framework
- **MongoDB** – database with vector search capability
- **Ollama Qwen3 Embeddings** – generates vector embeddings for semantic search
- **LangChain** – agent, tools, and workflow orchestration
- **BSON** – handles binary data for embedding storage

## Endpoints

### `POST /symptoms`

Interact with the RAG-based agent to get disease suggestions, seriousness assessment, treatment plans, and care recommendations.

**Request Body:**

| Parameter      | Type   | Required | Description                                           |
| -------------- | ------ | -------- | ----------------------------------------------------- |
| `diseasesLike` | string | yes      | The patient symptom description or disease-like query |
| `zipCode`      | string | no       | User's ZIP code (for care recommendations)            |

**Example Request:**

```json
POST http://localhost:4000/agenttest
{
  "diseasesLike": "fever and cough",
  "zipCode": "10001"
}
```

---

## Response

Returns a JSON object with the agent's reasoning steps and results, including top disease matches, seriousness assessment, treatment plan, and/or care recommendations.

**Fields:**

| Field                 | Type   | Description                              |
| --------------------- | ------ | ---------------------------------------- |
| `queryResults`        | array  | Top disease matches from semantic search |
| `summary`             | string | Summary of top suspected diseases        |
| `suspectedDisease`    | string | Most likely disease                      |
| `seriousnessResult`   | object | Seriousness assessment and reason        |
| `treatmentPlan`       | string | Treatment plan (if not severe)           |
| `careRecommendations` | object | Nearby care options (if severe)          |
