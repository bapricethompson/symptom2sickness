# Embedded Health Backend API

This backend provides a **semantic search API** over a database of diseases and patient symptom statements. It uses **vector embeddings** generated by the `qwen3-embedding` model from Ollama and performs vector similarity searches in MongoDB to return the most relevant disease or symptom descriptions.


---

## Features

- Search a database of diseases and patient symptom statements using natural language queries.
- Returns results ranked by semantic similarity.
- Easy-to-use REST API endpoint.
- Built with Node.js, Express, MongoDB, and Ollama embeddings.

---

## Tech Stack

- **Node.js** and **Express** – backend server and API framework  
- **MongoDB** – database with vector search capability  
- **Ollama Qwen3 Embeddings** – generates vector embeddings for semantic search  
- **BSON** – handles binary data for embedding storage

---

## Endpoints

### `GET /symptoms`

Search for diseases or symptom statements similar to a query.

**Query Parameters:**

| Parameter      | Type   | Required | Description |
|----------------|--------|----------|-------------|
| `searchQuery`  | string | yes      | The patient symptom description to search for |

**Example Request:**
GET http://localhost:4000/symptoms?searchQuery=fever%20and%20cough


---

## Response

Returns a JSON array of the top matches ranked by semantic similarity.

**Fields:**

| Field        | Type   | Description |
|--------------|--------|-------------|
| `disease`    | string | Name of the matched disease |
| `description`| string | Patient symptom statement from the database |
| `score`      | number | Semantic similarity score (higher = more similar) |

**Example Response:**

```json
[
  {
    "disease": "Influenza",
    "description": "Patient reports fever, chills, cough, and body aches.",
    "score": 0.92
  },
  {
    "disease": "Common Cold",
    "description": "Patient reports mild fever, sore throat, and cough.",
    "score": 0.85
  }
]
